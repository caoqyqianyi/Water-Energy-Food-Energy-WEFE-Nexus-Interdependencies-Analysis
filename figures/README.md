# Figures

Drop map products and dashboard screenshots here so they can be embedded in the
README or documentation. Suggested files (the README references these paths):

- `wefe_framework.png` — overall WEFE Nexus conceptual framework / workflow.
- `wefe_nexus_map.png` — composite WEFE Nexus map for the reference year.
- `pillar_maps.png` — pillar-specific maps (Water, Energy, Food, Ecosystem).
- `dashboard.png` — Power BI / QGIS decision-support dashboard screenshot.
- `hotspots.png` — nexus hotspot / synergy map.

Images in this folder are committed to git (the data-ignore rules only apply to
the `data/` directory). Use `.png` or `.jpg` and keep individual files
reasonably sized for web rendering.
